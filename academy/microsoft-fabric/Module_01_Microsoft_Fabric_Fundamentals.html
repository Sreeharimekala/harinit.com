Introduction to Microsoft Fabric

Microsoft Fabric is Microsoft's end-to-end, cloud-based data and analytics platform. It brings data integration, data engineering, data warehousing, data science, real-time intelligence, and business intelligence into one unified SaaS platform.

In simple terms:
Microsoft Fabric = One platform where you can collect data → store data → transform data → analyze data → build reports and insights.

Why was Microsoft Fabric introduced?

Traditionally, organizations often use multiple Azure services for analytics. For example, they might use Azure Data Factory for data movement, Azure Synapse Analytics for engineering and warehousing, Azure Data Lake Storage for storage, and Power BI for reporting.

Although these services work together, teams still need to manage separate resources, configurations, security, connections, and sometimes multiple copies of the same data.

Microsoft Fabric provides a more integrated experience by bringing these analytics capabilities together around a common storage foundation called OneLake.

Core idea of Microsoft Fabric

The important idea is that these workloads can work with data through OneLake, reducing unnecessary movement and duplication.

What is OneLake?

OneLake is one of the most important concepts in Microsoft Fabric.

You can think of it as:

"OneDrive for organizational data."

Instead of every analytics workload maintaining completely separate storage, Fabric provides OneLake as the common data lake for the organization.

Fabric also supports OneLake shortcuts, which allow Fabric to reference data in supported external locations without necessarily copying all of that data into another location.

1.5 SaaS vs PaaS

What is SaaS?

Software as a Service (SaaS) is a cloud computing model where users access ready-to-use software applications over the internet. The cloud provider manages everything, including the infrastructure, operating system, application updates, security, and maintenance. Users simply log in through a web browser or mobile app.

Key Features

No software installation required

Accessible from anywhere with an internet connection

Subscription-based pricing

Automatic updates and maintenance

Scalable based on user needs

Advantages

Low upfront cost

Easy to use

No maintenance required by users

Quick deployment

Accessible on multiple devices

Disadvantages

Limited customization

Requires internet connectivity

Less control over application features

Vendor dependency

Examples

Microsoft 365

Google Workspace

Salesforce

Dropbox

Zoom

What is PaaS?

Platform as a Service (PaaS) is a cloud computing model that provides developers with a complete platform to build, test, deploy, and manage applications. The cloud provider manages the infrastructure, operating system, networking, and middleware, while developers focus only on writing application code.

Key Features

Ready-to-use development environment

Built-in databases and middleware

Automatic scaling

Integrated development tools

Faster application deployment

Advantages

Faster application development

No infrastructure management

Supports team collaboration

Automatic updates

Cost-effective for developers

Disadvantages

Limited control over infrastructure

Vendor lock-in

Platform limitations

Compatibility issues when migrating

Examples

Microsoft Azure App Service

Google App Engine

AWS Elastic Beanstalk

Heroku

Red Hat OpenShift

SaaS is like ordering food from a restaurant. You simply eat the food without worrying about cooking or managing the kitchen.

Interview Questions

1. What is the difference between SaaS and PaaS?

Answer: SaaS provides ready-to-use software applications for end users, whereas PaaS provides a platform for developers to build, deploy, and manage applications.

2. Give examples of SaaS applications.

Answer: Microsoft 365, Google Workspace, Salesforce, Dropbox, Zoom, and Gmail.

3. Who manages the infrastructure in SaaS and PaaS?

Answer: In both SaaS and PaaS, the cloud provider manages the infrastructure.

4. Does PaaS require programming knowledge?

Azure offers both SaaS and PaaS services to meet various business and development needs.

29. Interview question: What are the roles in Microsoft Fabric Workspace?

A strong answer is:

Microsoft Fabric provides four primary workspace roles: Admin, Member, Contributor, and Viewer. Admin provides the highest workspace-management capabilities, Member supports broad collaboration and content management, Contributor is commonly used for users who create and modify Fabric content, and Viewer is primarily intended for users who consume content.

30. Interview question: RLS vs OLS

Answer:

Row-Level Security controls which rows of data a user can see, whereas Object-Level Security controls access to model objects such as specific tables or columns. For example, RLS can restrict a regional manager to India sales records, while OLS can hide a sensitive Salary or Profit column.
