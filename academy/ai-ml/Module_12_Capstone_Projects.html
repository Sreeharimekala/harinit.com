12.1

Customer Churn Prediction

Brief: a subscription business (telecom, OTT or SaaS) loses customers every month. Build a model that ranks customers by churn risk, decide how many to target with a retention offer, and estimate the value. Draws on: 6.7 (features), 7.6–7.7 (metrics, thresholds), 7.13 (boosting), 7.20 (worked example), 10.13 (deployment). Public data for your version: IBM Telco Customer Churn, KKBox churn (Kaggle).

Milestones

  1. Define churn precisely (no activity for 30 days? cancellation?) and the prediction moment; build features only from data before it.
  2. Baseline: a simple rule ("contract ending soon") and logistic regression.
  3. Gradient boosting with engineered features; stratified CV on ROC-AUC and PR-AUC.
  4. Choose the campaign size from expected value (offer cost vs saved margin), not a 0.5 threshold.
  5. Explain drivers; check performance by segment (plan, region, tenure).
  6. Ship a batch scoring job that writes a ranked list for the CRM.

Reference Solution

import numpy as np, pandas as pd, warnings; warnings.filterwarnings("ignore")
from sklearn.model_selection import train_test_split, cross_val_score, StratifiedKFold
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import roc_auc_score, average_precision_score
import lightgbm as lgb
rng = np.random.default_rng(121); n = 20000
df = pd.DataFrame({"tenure_m": rng.integers(1, 72, n), "monthly_fee": rng.choice([199, 399, 649, 999], n, p=[.3, .35, .25, .1]),
                   "watch_hours_30d": rng.gamma(2, 12, n), "watch_trend": rng.normal(0, 1, n), "payment_failures": rng.poisson(0.3, n),
                   "support_tickets": rng.poisson(0.6, n), "region": rng.choice(["north", "south", "east", "west"], n),
                   "annual_plan": rng.random(n) < 0.3})
logit = (-2.2 - 0.03 * df.tenure_m - 0.03 * df.watch_hours_30d - 0.7 * df.watch_trend + 0.8 * df.payment_failures
         + 0.35 * df.support_tickets - 1.2 * df.annual_plan + 0.001 * df.monthly_fee + 0.6 * (df.watch_hours_30d < 5))
df["churn"] = (rng.random(n) < 1 / (1 + np.exp(-logit))).astype(int)
X = pd.get_dummies(df.drop(columns="churn"), columns=["region"], dtype=float); y = df.churn
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)
cv = StratifiedKFold(5, shuffle=True, random_state=0)

          "LightGBM": lgb.LGBMClassifier(n_estimators=400, learning_rate=0.03, num_leaves=15, min_child_samples=50, verbose=-1, random_state=0)}
cv_auc = {name: cross_val_score(m, X_tr, y_tr, cv=cv, scoring="roc_auc").mean() for name, m in models.items()}
print("CV ROC-AUC:", {k: round(v, 3) for k, v in cv_auc.items()})
best_name = max(cv_auc, key=cv_auc.get)                                         # let validation decide — simpler models often win
best = models[best_name].fit(X_tr, y_tr); p = best.predict_proba(X_te)[:, 1]
print("selected:", best_name)
print(f"test ROC-AUC {roc_auc_score(y_te, p):.3f} · PR-AUC {average_precision_score(y_te, p):.3f} · base churn rate {y_te.mean():.1%}")

MARGIN_12M, OFFER_COST, SAVE_RATE = 4800, 300, 0.30                          # ₹ per saved subscriber; ₹ per offer; share saved
order = np.argsort(-p); churned = y_te.to_numpy()[order]
values = [(k, churned[:k].sum() * SAVE_RATE * MARGIN_12M - k * OFFER_COST) for k in range(50, len(order), 50)]
k_best, v_best = max(values, key=lambda kv: kv[1])
print(f"best campaign: top {k_best / len(order):.0%} of customers → expected value ₹{v_best / len(order) * 1e6 / 1e5:.1f} lakh per 10 lakh subscribers")
seg = X_te.assign(p=p, y=y_te).groupby(df.loc[X_te.index, "annual_plan"].map({True: "annual", False: "monthly"}))
print("AUC by plan:", {k: round(roc_auc_score(g.y, g.p), 3) for k, g in seg})

12.2

Sales Forecasting

Brief: a grocery chain with 20 stores must order perishables daily. Forecast each store's sales for the next 14 days so ordering reduces both waste and stock-outs. Draws on: 6.12 (time series), 6.7 (lag features), 7.13 (LightGBM). Public data: Rossmann Store Sales, M5 Forecasting (Walmart), Corporación Favorita (Kaggle).

Milestones

  1. EDA: trend, weekly and yearly seasonality, festivals, promotions, store differences.
  2. Baselines: last week's same day (seasonal naive) and a moving average.
  3. One global gradient-boosting model across stores with lag, rolling, calendar, holiday and promotion features.
  4. Backtest with rolling time-based splits — never random splits.
  5. Report error in units and ₹ (MAE, WAPE); check by store and around festivals.
  6. Turn forecasts into order quantities with a safety buffer; schedule daily runs.

Reference Solution

Cell — 20 stores × 2 years, global LightGBM vs seasonal-naive with rolling backtestsPython
import numpy as np, pandas as pd, lightgbm as lgb, matplotlib.pyplot as plt
rng = np.random.default_rng(122)
dates = pd.date_range("2024-11-01", "2026-10-31", freq="D")
festivals = pd.to_datetime(["2024-11-01", "2025-03-14", "2025-08-27", "2025-10-20", "2025-10-21", "2026-03-04", "2026-09-14", "2026-11-08"])
rows = []
for s in range(20):
    base, growth = rng.uniform(800, 2500), rng.uniform(0.0, 0.0006)
    t = np.arange(len(dates))
    weekly = 1 + 0.25 * (dates.dayofweek >= 5) + 0.05 * (dates.dayofweek == 4)
    yearly = 1 + 0.12 * np.sin(2 * np.pi * (dates.dayofyear - 80) / 365)
    promo = rng.random(len(dates)) < 0.08
    fest = np.isin(dates.normalize(), festivals) | np.isin(dates.normalize(), festivals - pd.Timedelta(days=1))
    sales = base * (1 + growth * t) * weekly * yearly * (1 + 0.3 * promo) * (1 + 0.6 * fest) * rng.lognormal(0, 0.08, len(dates))
    rows.append(pd.DataFrame({"date": dates, "store": s, "promo": promo.astype(int), "festival": fest.astype(int), "sales": sales.round()}))
df = pd.concat(rows).sort_values(["store", "date"]).reset_index(drop=True)

def features(d, horizon=14):
    g = d.groupby("store").sales
    for lag in (horizon, horizon + 7, 28, 364):                         # only lags ≥ horizon are available at forecast time
        d[f"lag_{lag}"] = g.shift(lag)
    d["roll7_mean"] = g.shift(horizon).rolling(7).mean().reset_index(level=0, drop=True)
    d["roll28_mean"] = g.shift(horizon).rolling(28).mean().reset_index(level=0, drop=True)
    d["dow"], d["doy"], d["month"] = d.date.dt.dayofweek, d.date.dt.dayofyear, d.date.dt.month
    return d
df = features(df)
FEATS = ["store", "promo", "festival", "lag_14", "lag_21", "lag_28", "lag_364", "roll7_mean", "roll28_mean", "dow", "doy", "month"]

results = []
for cutoff in pd.to_datetime(["2026-07-01", "2026-08-01", "2026-09-01", "2026-10-01"]):          # rolling-origin backtest
    train = df[(df.date < cutoff) & df.lag_364.notna()]; test = df[(df.date >= cutoff) & (df.date < cutoff + pd.Timedelta(days=14))]
    model = lgb.LGBMRegressor(n_estimators=500, learning_rate=0.05, num_leaves=31, objective="l1", verbose=-1, random_state=0)
    model.fit(train[FEATS], train.sales, categorical_feature=["store"])
    pred = model.predict(test[FEATS]); naive = test.lag_14.to_numpy()        # same weekday two weeks earlier (available at forecast time)
    wape = lambda f: np.abs(test.sales - f).sum() / test.sales.sum()
    results.append({"cutoff": cutoff.date(), "WAPE LightGBM": wape(pred), "WAPE seasonal-naive": wape(naive)})
res = pd.DataFrame(results); print(res.round(3).to_string(index=False)); print("\nmean:", res.drop(columns="cutoff").mean().round(3).to_dict())

store0 = test[test.store == 0]
fig, ax = plt.subplots(figsize=(9, 2.8))
ax.plot(store0.date, store0.sales, marker="o", label="actual", color="#8da0b2"); ax.plot(store0.date, pred[test.store.to_numpy() == 0], marker="o", label="LightGBM", color="#ffb454")
ax.plot(store0.date, store0.lag_14, ls="--", label="seasonal naive", color="#4ea8de"); ax.legend(frameon=False, fontsize=8); ax.set_title("Store 0, last backtest window", fontsize=9)
plt.tight_layout()
cutoff WAPE LightGBM WAPE seasonal-naive 2026-07-01 0.073 0.115 2026-08-01 0.070 0.120 2026-09-01 0.097 0.167 2026-10-01 0.070 0.118 mean: {'WAPE LightGBM': 0.078, 'WAPE seasonal-naive': 0.13}

Project-Specific Rubric Points

  • Every feature is available at forecast time (lags ≥ horizon); backtests use rolling origins
  • Error reported in business terms (WAPE, ₹ of waste / lost sales) and around festivals
  • Forecasts converted into orders with a stated service level
  • Stretch: probabilistic forecasts (quantile regression) for safety stock; hierarchical reconciliation (store → region → chain)

House Price Prediction

Brief: a property portal wants an instant price estimate for apartment listings in Hyderabad, shown with a range, to flag over-priced listings and help sellers set prices. Draws on: 5.12 (regression), 6.5–6.6 (outliers, transforms), 7.4 (regularisation), 7.13 (CatBoost categoricals), 7.15 (interpretation). Public data: Kaggle House Prices (Ames), Indian city housing datasets (Magicbricks / 99acres scrapes on Kaggle — check terms).

Milestones

  1. Clean listings: duplicates, unit errors (lakh vs crore), impossible areas; log-transform price.
  2. Baseline: price per sq ft × area by locality; then linear regression with regularisation.
  3. CatBoost with locality and builder as categorical features.
  4. Evaluate MAE and MAPE in ₹; check by locality and price band; prediction intervals via quantile models.
  5. Explain an individual estimate (top contributing features).

Reference Solution

Cell — locality-aware pricing with CatBoost, intervals and segment errorsPython
import numpy as np, pandas as pd, warnings; warnings.filterwarnings("ignore")
from catboost import CatBoostRegressor
from sklearn.model_selection import train_test_split
from sklearn.linear_model import RidgeCV
rng = np.random.default_rng(123); n = 6000
localities = {"Gachibowli": 9500, "Kondapur": 8200, "Banjara Hills": 14500, "Kukatpally": 6800, "Miyapur": 5600,
              "LB Nagar": 5200, "Uppal": 5000, "Manikonda": 7400, "Kokapet": 10500, "Madhapur": 10800}
loc = rng.choice(list(localities), n)
area = rng.normal(1350, 400, n).clip(450, 4000).round()
bhk = np.clip(np.round(area / 550 + rng.normal(0, 0.4, n)), 1, 5)
age = rng.integers(0, 25, n); floor = rng.integers(0, 25, n); gated = rng.random(n) < 0.6
metro_km = rng.gamma(2, 1.5, n).round(1)
ppsf = np.array([localities[l] for l in loc]) * (1 - 0.012 * age) * (1 + 0.08 * gated) * (1 - 0.025 * metro_km) * (1 + 0.004 * floor)
price_lakh = (area * ppsf * rng.lognormal(0, 0.09, n) / 1e5).round(1)
df = pd.DataFrame({"locality": loc, "area_sqft": area, "bhk": bhk, "age_yrs": age, "floor": floor, "gated": gated.astype(int), "metro_km": metro_km, "price_lakh": price_lakh})
df.loc[rng.choice(n, 25, replace=False), "price_lakh"] *= 100                 # data-entry errors: crore typed as lakh
med_ppsf = (df.price_lakh * 1e5 / df.area_sqft).groupby(df.locality).transform("median")
bad = (df.price_lakh * 1e5 / df.area_sqft) > 5 * med_ppsf
print(f"removed {bad.sum()} listings with impossible price per sq ft"); df = df[~bad]

X, y = df.drop(columns="price_lakh"), np.log(df.price_lakh)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0)
true = np.exp(y_te)
def report(name, pred_lakh):
    mae = np.abs(pred_lakh - true).mean(); mape = (np.abs(pred_lakh - true) / true).mean()
    print(f"{name:<30} MAE ₹{mae:5.1f} L   MAPE {mape:.1%}")
ppsf_tr = (np.exp(y_tr) * 1e5 / X_tr.area_sqft).groupby(X_tr.locality).median()
report("baseline: locality ₹/sqft × area", X_te.locality.map(ppsf_tr) * X_te.area_sqft / 1e5)
ridge = RidgeCV(alphas=[0.1, 1, 10]).fit(pd.get_dummies(X_tr, dtype=float), y_tr)
report("ridge on log price", np.exp(ridge.predict(pd.get_dummies(X_te, dtype=float).reindex(columns=pd.get_dummies(X_tr).columns, fill_value=0))))
cb = CatBoostRegressor(iterations=800, depth=6, learning_rate=0.05, loss_function="RMSE", verbose=0, random_seed=0, cat_features=["locality"])
cb.fit(X_tr, y_tr); report("CatBoost on log price", np.exp(cb.predict(X_te)))

lo = CatBoostRegressor(iterations=500, depth=6, loss_function="Quantile:alpha=0.1", verbose=0, random_seed=0, cat_features=["locality"]).fit(X_tr, y_tr)
hi = CatBoostRegressor(iterations=500, depth=6, loss_function="Quantile:alpha=0.9", verbose=0, random_seed=0, cat_features=["locality"]).fit(X_tr, y_tr)
inside = ((true >= np.exp(lo.predict(X_te))) & (true <= np.exp(hi.predict(X_te)))).mean()
print(f"80% prediction interval covers {inside:.0%} of test prices")
listing = X_te.iloc[[0]]
print(f"\nexample: {listing.iloc[0].to_dict()}\n  estimate ₹{np.exp(cb.predict(listing))[0]:.1f} L (range ₹{np.exp(lo.predict(listing))[0]:.0f}–{np.exp(hi.predict(listing))[0]:.0f} L), actual ₹{true.iloc[0]:.1f} L")
err = pd.DataFrame({"loc": X_te.locality, "ape": np.abs(np.exp(cb.predict(X_te)) - true) / true}).groupby("loc").ape.mean().sort_values()
print("MAPE by locality (best → worst):", err.round(3).to_dict())

Fraud Detection

Brief: a UPI payments app sees about 0.3% fraudulent transactions. Score each transaction in real time so the riskiest are blocked or sent for step-up verification, without annoying genuine users. Draws on: 6.5 (anomalies), 6.7 (velocity features), 7.6–7.7 (imbalance, PR-AUC, cost thresholds), 10.10 (drift). Public data: Kaggle Credit Card Fraud (European cardholders), IEEE-CIS Fraud Detection, PaySim (synthetic mobile money).

Milestones

  1. Engineer behaviour features: amount vs the user's usual, transactions in the last hour, new device or payee, night-time.
  2. Split by time (train on earlier weeks, test on later) — fraud patterns evolve.
  3. Compare an unsupervised detector (Isolation Forest) with supervised boosting; use PR-AUC.
  4. Pick block / step-up thresholds from the cost of missed fraud vs false declines, and report expected savings.
  5. Plan monitoring: fraud rate, alert volumes, drift — fraudsters adapt.

Reference Solution

Cell — velocity features, time split, unsupervised vs supervised, cost-based thresholdsPython
import numpy as np, pandas as pd, lightgbm as lgb, warnings; warnings.filterwarnings("ignore")
from sklearn.ensemble import IsolationForest
from sklearn.metrics import average_precision_score, roc_auc_score
rng = np.random.default_rng(124)
n_users, n = 4000, 160_000
users = pd.DataFrame({"user": range(n_users), "typical_amt": rng.lognormal(6.2, 0.8, n_users)})
tx = pd.DataFrame({"user": rng.integers(0, n_users, n), "ts": np.sort(rng.uniform(0, 56 * 86400, n))})   # 8 weeks
tx = tx.merge(users, on="user").sort_values("ts").reset_index(drop=True)
tx["amount"] = (tx.typical_amt * rng.lognormal(0, 0.5, n)).round()
tx["hour"] = (tx.ts % 86400 // 3600).astype(int)
tx["new_payee"] = (rng.random(n) < 0.15).astype(int); tx["new_device"] = (rng.random(n) < 0.03).astype(int)
fraud = rng.random(n) < 0.003                                                   # account-takeover pattern
tx.loc[fraud, "amount"] = (tx.loc[fraud, "typical_amt"] * rng.uniform(3, 15, fraud.sum())).round()
tx.loc[fraud, "new_payee"] = (rng.random(fraud.sum()) < 0.85).astype(int)
tx.loc[fraud, "new_device"] = (rng.random(fraud.sum()) < 0.6).astype(int)
tx.loc[fraud, "hour"] = rng.choice([0, 1, 2, 3, 23, 14, 19], fraud.sum())
tx["fraud"] = fraud.astype(int)

g = tx.groupby("user")                                                          # behaviour features (past-only)
tx["user_median_amt"] = g.amount.transform(lambda s: s.shift().expanding().median()).fillna(tx.amount)
tx["amt_ratio"] = tx.amount / tx.user_median_amt
tx["tx_last_hour"] = g.ts.transform(lambda s: pd.Series(np.searchsorted(s.values, s.values, side="right")     # count of this user's
                                                          - np.searchsorted(s.values, s.values - 3600), index=s.index) - 1)   # tx in the past hour
tx["night"] = tx.hour.isin([0, 1, 2, 3, 4]).astype(int)
FEATS = ["amount", "amt_ratio", "tx_last_hour", "new_payee", "new_device", "night", "hour"]
train, test = tx[tx.ts < 42 * 86400], tx[tx.ts >= 42 * 86400]                    # weeks 1–6 train, 7–8 test
print(f"train {len(train):,} tx ({train.fraud.mean():.2%} fraud) · test {len(test):,} tx ({test.fraud.sum()} frauds)")

iso = IsolationForest(n_estimators=200, contamination=0.003, random_state=0).fit(train[FEATS])
s_iso = -iso.score_samples(test[FEATS])
gbm = lgb.LGBMClassifier(n_estimators=300, learning_rate=0.05, num_leaves=15, scale_pos_weight=20, verbose=-1, random_state=0).fit(train[FEATS], train.fraud)
s_gbm = gbm.predict_proba(test[FEATS])[:, 1]
for name, s in [("Isolation Forest (no labels)", s_iso), ("LightGBM (supervised)", s_gbm)]:
    print(f"{name:<30} PR-AUC {average_precision_score(test.fraud, s):.3f}   ROC-AUC {roc_auc_score(test.fraud, s):.3f}")

LOSS_PER_FRAUD_SHARE, FALSE_DECLINE_COST = 1.0, 150                              # lose the fraud amount; ₹150 goodwill per wrongly blocked user
best = None
for t in np.quantile(s_gbm, [0.99, 0.995, 0.998, 0.999]):
    flag = s_gbm >= t; caught = test.fraud.to_numpy()[flag].astype(bool)
    saved = test.amount.to_numpy()[flag][caught].sum(); fp = (~caught).sum()
    net = saved * LOSS_PER_FRAUD_SHARE - fp * FALSE_DECLINE_COST
    print(f"block top {flag.mean():.2%}: catches {caught.sum()}/{test.fraud.sum()} frauds, {fp} genuine users declined, net saving ₹{net / 1e5:.1f} L")

from sklearn.decomposition import TruncatedSVD
from sklearn.preprocessing import normalize

n_users, n_items, k_true = 3000, 600, 8
U, V = rng.normal(size=(n_users, k_true)), rng.normal(size=(n_items, k_true))
pop = rng.zipf(1.6, n_items).clip(1, 200).astype(float)                          # a few bestsellers, a long tail
rows = []

    p = np.exp(scores - scores.max()); p /= p.sum()
    items = rng.choice(n_items, size=rng.integers(8, 40), replace=False, p=p)
    rows += [(u, i, t) for t, i in enumerate(items)]                              # t = order of interaction
inter = pd.DataFrame(rows, columns=["user", "item", "t"])

R = csr_matrix((np.ones(len(train)), (train.user, train.item)), shape=(n_users, n_items))
print(f"{len(inter):,} interactions · density {len(train) / (n_users * n_items):.2%}")

        s = score_fn(u).astype(float); s[R[u].indices] = -np.inf                  # don't recommend what they already have

        ndcg.append(1 / np.log2(np.where(top == held)[0][0] + 2) if hit else 0)

user_f, item_f = svd.transform(R), svd.components_.T
results = {"popularity": evaluate(lambda u: popularity),

print(pd.DataFrame(results).T.round(3).to_string())

import re, json
HELP = {"late-delivery": "If an order is more than 30 minutes late, you get a 20% voucher automatically.",
        "missing-item": "For a missing item, report it within 2 hours of delivery in the app for a refund to your wallet.",
        "cancellation": "Orders can be cancelled free within 60 seconds of placing them; after that the restaurant may charge."}
ORDERS = {"FD-4410": {"status": "picked up", "eta_min": 12, "late_by_min": 0}, "FD-9902": {"status": "on the way", "eta_min": 25, "late_by_min": 35}}
stems = lambda t: {w[:5] for w in re.findall(r"[a-z]+", t.lower()) if len(w) > 2}            # crude stemming: cancel ≈ cancelled
def search_help(query):
    best = max(HELP, key=lambda k: len(stems(query) & stems(k + " " + HELP[k])))
    return {"article": best, "text": HELP[best]}
def get_order(order_id): return ORDERS.get(order_id, {"error": "not found"})
def handoff(summary): return {"ticket": "HD-2219", "queue": "priority", "summary": summary}

class Assistant:
    def __init__(self):
        self.history, self.state = [], {"order_id": None, "pending": None}
    def decide(self, msg):
        """STAND-IN for the LLM: in production the model reads the history + tool schemas and returns tool calls."""
        m = msg.lower()
        if oid := re.search(r"FD-\d{4}", msg.upper()): self.state["order_id"] = oid.group()
        if re.search(r"agent|human|complain", m): return ("handoff", {"summary": self.summary()})
        wants_status = re.search(r"where|status|late|eta|arriv", m) or (oid and self.state["pending"] == "get_order")
        if wants_status and self.state["order_id"]:
            self.state["pending"] = None; return ("get_order", {"order_id": self.state["order_id"]})
        if wants_status:
            self.state["pending"] = "get_order"; return ("ask", "Could you share your order ID? It starts with FD-.")
        if re.search(r"refund|missing|cancel|voucher|policy", m): return ("search_help", {"query": msg})
        if re.search(r"hi|hello", m): return ("ask", "Hi! I can track orders and help with refunds, missing items and cancellations.")
        return ("ask", "I can help with orders, refunds and delivery issues. For anything else, please visit our help centre.")
    def summary(self):
        return f"Customer order {self.state['order_id'] or 'unknown'}; conversation: " + " | ".join(h["user"] for h in self.history[-3:])
    def reply(self, msg):
        action, arg = self.decide(msg)
        if action == "ask": text = arg
        elif action == "get_order":
            o = get_order(**arg)
            text = (f"Your order {arg['order_id']} is {o['status']}, about {o['eta_min']} min away."
                    + (f" It's running {o['late_by_min']} min late, so a 20% voucher has been added to your account." if o.get("late_by_min", 0) > 30 else ""))
        elif action == "search_help":
            r = search_help(**arg); text = f"{r['text']} [help: {r['article']}]"
        else:
            r = handoff(**arg); text = f"I've connected you to a support agent (ticket {r['ticket']}). They can see our chat, so you won't need to repeat yourself."
        self.history.append({"user": msg, "bot": text, "action": action})
        return text

The agent's job is orchestration and explanation: decide which items to look at, call the tools, handle odd cases (a supplier is out of stock, a festival is coming), and write a clear note for the manager. Keeping arithmetic in tools — not in the LLM's head — is what makes the system reliable.

Cell — tools, reorder policy, guardrails and human approval; scripted stand-in for the LLM's reasoningPython
import numpy as np, pandas as pd, json
rng = np.random.default_rng(129)
CATALOG = pd.DataFrame({
    "sku": ["PARA-500", "ORS-21", "VITC-60", "INSUL-10", "MASK-N95", "BANDAGE"],
    "name": ["Paracetamol 500mg", "ORS sachets", "Vitamin C 60s", "Insulin pen 10ml", "N95 masks", "Bandage roll"],
    "unit_cost": [12, 18, 140, 780, 95, 25], "lead_days": [2, 2, 5, 3, 4, 2], "max_order": [2000, 1500, 300, 120, 1000, 800]})
daily_mean = {"PARA-500": 85, "ORS-21": 40, "VITC-60": 9, "INSUL-10": 6, "MASK-N95": 30, "BANDAGE": 14}
on_hand = {"PARA-500": 140, "ORS-21": 260, "VITC-60": 90, "INSUL-10": 11, "MASK-N95": 70, "BANDAGE": 300}
history = {s: rng.poisson(m, 60) for s, m in daily_mean.items()}                    # last 60 days of sales

# ── tools (deterministic, unit-tested, permission-scoped) ──
def get_stock(sku): return {"sku": sku, "on_hand": on_hand[sku]}
def forecast(sku, days):
    h = history[sku]; mu, sd = h[-28:].mean(), h[-28:].std()
    return {"sku": sku, "days": days, "mean": round(mu * days, 1), "sd": round(sd * np.sqrt(days), 1)}
def reorder_qty(sku, service_z=1.65):                                                 # ~95% service level
    row = CATALOG.set_index("sku").loc[sku]; f = forecast(sku, int(row.lead_days) + 7)   # cover lead time + a week
    need = f["mean"] + service_z * f["sd"] - on_hand[sku]
    return int(min(max(np.ceil(need), 0), row.max_order)), f
POS = []
def create_po(sku, qty, approved_by=None):
    POS.append({"sku": sku, "qty": qty, "approved_by": approved_by or "auto"}); return {"po": f"PO-{1000 + len(POS)}", "sku": sku, "qty": qty}

# ── guardrails ──
DAILY_BUDGET, APPROVAL_ABOVE = 62_000, 25_000
def manager_approves(request):                                                        # STAND-IN for a Teams/Slack approval card
    print(f"   ⏸ approval needed: {request['reason']}"); return request["sku"] != "MASK-N95"    # manager declines masks this time

# ── agent loop: STAND-IN for the LLM, which would choose tools and write the reasons ──
spent, report, plan = 0, [], []
for sku in CATALOG.sku:
    stock = get_stock(sku); qty, f = reorder_qty(sku)
    plan.append((stock["on_hand"] / max(f["mean"] / f["days"], 0.1), sku, stock, qty, f))
for days_left, sku, stock, qty, f in sorted(plan):                                    # most urgent first, so the budget goes where it matters
    cost = qty * int(CATALOG.set_index("sku").loc[sku, "unit_cost"])
    if qty == 0:
        report.append(f"{sku}: no order — {stock['on_hand']} on hand covers ~{days_left:.0f} days"); continue
    approver = None
    if cost > APPROVAL_ABOVE:
        ok = manager_approves({"sku": sku, "reason": f"{sku} × {qty} = ₹{cost:,} (stock lasts ~{days_left:.0f} days)"})
        if not ok: report.append(f"{sku}: NOT ORDERED — manager declined"); continue
        approver = "store manager"
    if spent + cost > DAILY_BUDGET:
        report.append(f"{sku}: DEFERRED to tomorrow ({days_left:.0f} days of stock) — would exceed today's budget (₹{spent + cost:,} > ₹{DAILY_BUDGET:,})"); continue
    po = create_po(sku, qty, approver); spent += cost
    report.append(f"{sku}: {po['po']} for {qty} (₹{cost:,}) — {stock['on_hand']} on hand ≈ {days_left:.1f} days; "
                  f"forecast {f['mean']:.0f} ± {f['sd']:.0f} over {f['days']} days")
print("\nMorning restock report")
for line in report: print(" •", line)
print(f"total committed: ₹{spent:,} of ₹{DAILY_BUDGET:,} budget · POs: {json.dumps(POS)}")

Cell — simulate 60 days: agent policy vs the store's current "reorder 500 when it looks low" habitPython
def simulate(policy, days=60, seed=7):
    r = np.random.default_rng(seed); stock = {s: 4 * m for s, m in daily_mean.items()}; pipeline = []
    lost = holding = orders = 0
    for d in range(days):
        for arr in [p for p in pipeline if p[0] == d]: stock[arr[1]] += arr[2]
        pipeline = [p for p in pipeline if p[0] > d]
        for s, m in daily_mean.items():
            demand = r.poisson(m); sold = min(demand, stock[s]); lost += demand - sold; stock[s] -= sold
            holding += stock[s] * CATALOG.set_index("sku").loc[s, "unit_cost"] * 0.0007        # ~25% a year carrying cost
            incoming = sum(q for t, sk, q in pipeline if sk == s)
            q = policy(s, stock[s] + incoming, m)
            if q > 0:
                pipeline.append((d + int(CATALOG.set_index("sku").loc[s, "lead_days"]), s, q)); orders += 1
    return {"lost sales (units)": lost, "holding cost ₹": round(holding), "orders placed": orders}
def agent_policy(s, position, m):
    lead = int(CATALOG.set_index("sku").loc[s, "lead_days"]); cover = lead + 7
    target = m * cover + 1.65 * np.sqrt(m * cover)
    return int(target - position) if position < m * lead + 1.65 * np.sqrt(m * lead) else 0
def habit_policy(s, position, m): return 500 if position < 100 else 0
print(pd.DataFrame({"agent policy": simulate(agent_policy), "current habit": simulate(habit_policy)}).to_string())

The policy places more, smaller orders than the habit — but loses far fewer sales and ties up much less cash in stock. If ordering is costly (delivery fees, staff time), add a fixed cost per order to the simulation and tune the review period.

In production, swap the stand-in loop for an LLM with these tools as JSON schemas (11.7) or a LangGraph workflow with an interrupt before create_po (11.9) — the tools, budget, approval rule and this simulation stay unchanged and become your test harness.
