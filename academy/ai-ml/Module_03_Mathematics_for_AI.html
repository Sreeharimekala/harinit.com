Variables, Functions and the Linear Model

A function maps an input to an output. The simplest model in ML is a straight line:

\[ \hat{y} = w\,x + b \]\(x\) = input (feature) · \(w\) = weight (slope) · \(b\) = bias (intercept) · \(\hat{y}\) = prediction ("y-hat")

With several inputs it becomes a weighted sum — the core of linear regression, logistic regression and every neuron in a neural network:

\[ \hat{y} = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b = \sum_{i=1}^{n} w_i x_i + b \]\(\sum\) ("sigma") means "add up for i from 1 to n"
Cell — a house-price modelPython
# price (₹ lakh) = 0.08 × area(sq ft) + 5 × bedrooms − 0.4 × age(years) + 10
w = [0.08, 5, -0.4]
b = 10
house = [1200, 3, 8]                   # 1,200 sq ft, 3 bedrooms, 8 years old

y_hat = sum(wi * xi for wi, xi in zip(w, house)) + b
print(f"Predicted price: ₹{y_hat:.1f} lakh")
Predicted price: ₹117.8 lakh

Solving and Rearranging Equations

Solving means isolating the unknown by doing the same thing to both sides. Example: what area gives a ₹120 lakh prediction (3 bedrooms, 8 years)?

\[ 120 = 0.08x + 15 - 3.2 + 10 \;\Rightarrow\; 0.08x = 98.2 \;\Rightarrow\; x = 1227.5 \text{ sq ft} \]

The same skill lets you invert a transformation. Standardisation (used before most ML algorithms) and its inverse:

\[ z = \frac{x - \mu}{\sigma} \qquad\Longleftrightarrow\qquad x = \mu + z\,\sigma \]\(\mu\) = mean, \(\sigma\) = standard deviation; \(z\) says "how many standard deviations from the mean"
CellPython
mu, sigma = 70, 5            # exam scores: mean 70, std dev 5
x = 80
z = (x - mu) / sigma
print("z =", z)              # 2 standard deviations above average
print("back to x:", mu + z * sigma)
z = 2.0 back to x: 80.0

Quadratics: The Shape of Error

Squared error \((y - \hat{y})^2\) is a quadratic — a U-shaped curve with a single lowest point. That shape is why many ML problems have one best answer you can find by "rolling downhill" (Lesson 3.11).

import numpy as np
import matplotlib.pyplot as plt

w = np.linspace(-1, 5, 200)
error = (6 - w * 2) ** 2              # true y = 6, input x = 2, prediction = w·x

fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(w, error)
ax.scatter([3], [0], color="orange", zorder=3, label="minimum at w = 3")
ax.set_xlabel("weight w"); ax.set_ylabel("squared error"); ax.legend()
plt.show()

# Roots of x² − 5x + 6 = 0 with the quadratic formula / NumPy

Exponents, Logarithms & Key Functions

Exponentials describe growth and turn any number into a positive one; logarithms undo exponentials and turn multiplication into addition. Together they create the functions you'll meet constantly in ML: sigmoid and softmax (turning scores into probabilities) and log-loss (measuring how wrong a probability was).

Exponents and the Number e

RuleExample
\(a^m \cdot a^n = a^{m+n}\)\(2^3 \cdot 2^2 = 2^5 = 32\)
\(a^{-n} = 1/a^n\)\(10^{-2} = 0.01\)
\(a^0 = 1\)—
\(e \approx 2.71828\)The natural base; \(e^x\) is its own derivative (Lesson 3.8)

Logarithms: The Inverse of Exponentials

\[ \log_b(y) = x \quad\Longleftrightarrow\quad b^x = y \qquad\qquad \ln(y) = \log_e(y) \]
RuleWhy ML cares
\(\log(ab) = \log a + \log b\)A product of thousands of tiny probabilities becomes a manageable sum (log-likelihood)
\(\log(a^k) = k \log a\)Simplifies powers in likelihoods
\(\log\) is increasingMaximising \(\log L\) gives the same answer as maximising \(L\)
\(\log\) compresses large valuesLog-transforming skewed features (income, prices) before modelling

import numpy as np

print("product:", np.prod(probs))           # underflows to 0.0 — information lost

incomes = np.array([18_000, 25_000, 40_000, 90_000, 2_500_000])

Sigmoid: Any Score → a Probability

\[ \sigma(z) = \frac{1}{1 + e^{-z}} \]maps \(-\infty \dots +\infty\) to \(0 \dots 1\); \(\sigma(0) = 0.5\) — used in logistic regression and binary classifiers

Softmax: Several Scores → Probabilities That Sum to 1

\[ \text{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}} \]used for multi-class outputs and in attention inside Transformers (Module 11)

Log-Loss: How Wrong Was the Probability?

\[ L = -\big[\,y \log \hat{p} + (1 - y)\log(1 - \hat{p})\,\big] \]binary cross-entropy: confident and right → near 0; confident and wrong → very large
CellPython
import matplotlib.pyplot as plt

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def softmax(z):
    e = np.exp(z - np.max(z))        # subtract the max for numerical stability (Lesson 3.12)
    return e / e.sum()

print("sigmoid:", sigmoid(np.array([-4, 0, 2.5])).round(3))
scores = np.array([2.0, 1.0, 0.1])   # e.g. cat, dog, rabbit
print("softmax:", softmax(scores).round(3), "sum =", softmax(scores).sum())

for p in (0.9, 0.6, 0.1):            # true label y = 1
    print(f"p̂ = {p}: log-loss = {-np.log(p):.3f}")

z = np.linspace(-6, 6, 200)
fig, (a1, a2) = plt.subplots(1, 2, figsize=(9, 3))
a1.plot(z, sigmoid(z)); a1.axhline(0.5, ls="--", c="grey"); a1.set_title("sigmoid σ(z)")
p = np.linspace(0.01, 0.99, 200)
a2.plot(p, -np.log(p), label="y = 1"); a2.plot(p, -np.log(1 - p), label="y = 0")
a2.set_title("log-loss vs predicted p̂"); a2.legend()
fig.tight_layout(); plt.show()
sigmoid: [0.018 0.5 0.924] softmax: [0.659 0.242 0.099] sum = 1.0 p̂ = 0.9: log-loss = 0.105 p̂ = 0.6: log-loss = 0.511 p̂ = 0.1: log-loss = 2.303

Exponential Growth and Decay

\[ A(t) = A_0\, e^{kt} \qquad (k > 0 \text{ growth},\; k < 0 \text{ decay}) \]

Examples in ML: learning-rate decay schedules, exponentially weighted moving averages (used inside the Adam optimiser), and "exploding/vanishing" gradients when numbers are multiplied many times.

Exponentials (especially eˣ) make values positive and model growth and decay; logarithms invert them and turn products into sums, so ML works with log-probabilities to avoid underflow and maximises log-likelihood instead of likelihood. Log transforms compress skewed features. The sigmoid 1/(1 + e⁻ᶻ) maps any score to a probability for binary classification, softmax normalises a vector of scores into probabilities summing to one for multi-class outputs and attention, and log-loss (cross-entropy) heavily penalises confident wrong predictions.

L1 and L2 norms reappear as regularisation (Module 7): adding \(\lambda\|\mathbf{w}\|_1\) (Lasso) or \(\lambda\|\mathbf{w}\|_2^2\) (Ridge) to the loss keeps model weights small.

A vector is an ordered list of numbers representing a point or direction in n-dimensional space; in ML each example, embedding or set of weights is a vector. Vectors add element-wise and scale by multiplication. The L2 norm √Σvᵢ² measures Euclidean length and the L1 norm Σ|vᵢ| Manhattan length; distance is the norm of the difference. Unit vectors keep only direction. Because distances depend on feature scales, distance-based algorithms require standardised features, and L1/L2 norms of weights are used for Lasso and Ridge regularisation.

Dot Product & Similarity

The dot product multiplies two vectors into a single number. It's everywhere: a model's prediction is a dot product of weights and features; cosine similarity (a normalised dot product) powers recommendation, semantic search and the attention mechanism inside LLMs.

Two Ways to See It

\[ \mathbf{a}\cdot\mathbf{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \dots + a_nb_n \qquad\quad \mathbf{a}\cdot\mathbf{b} = \|\mathbf{a}\|\,\|\mathbf{b}\|\cos\theta \]algebraic (multiply and add) · geometric (lengths × cosine of the angle between them)

A Prediction Is a Dot Product

import numpy as np

x = np.array([1200, 3, 8])
b = 10

Cosine Similarity

\[ \cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|} \in [-1,\, 1] \]compares direction only — ignores length (e.g. how long a document is)
Cell — tiny "embeddings" for searchPython
def cosine(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

# dimensions: [kitchen, electrical, decor, price-level]
items = {
    "Electric Kettle": np.array([0.9, 0.9, 0.1, 0.4]),
    "Toaster":         np.array([0.9, 0.8, 0.0, 0.5]),
    "Table Lamp":      np.array([0.0, 0.7, 0.9, 0.5]),
    "Wall Clock":      np.array([0.1, 0.2, 0.9, 0.3]),
}
query = np.array([1.0, 0.8, 0.0, 0.3])          # "something electric for the kitchen"
ranked = sorted(items, key=lambda k: cosine(query, items[k]), reverse=True)
for name in ranked:
    print(f"{name:<16} {cosine(query, items[name]):.3f}")
Electric Kettle 0.989 Toaster 0.985 Table Lamp 0.434 Wall Clock 0.273

Real systems do exactly this with embeddings from a language model: convert products, documents or questions into vectors, then return the ones with the highest cosine similarity (vector search — Module 11).

Projection: The Shadow of One Vector on Another

\[ \text{proj}_{\mathbf{b}}\,\mathbf{a} = \frac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{b}}\;\mathbf{b} \]the part of \(\mathbf{a}\) that points along \(\mathbf{b}\) — the idea behind PCA (Lesson 3.7) and least squares (3.17)
CellPython
a = np.array([3.0, 4.0])
b = np.array([1.0, 0.0])
proj = (a @ b) / (b @ b) * b
print("projection of a on b:", proj, "  remainder:", a - proj, "  remainder · b =", (a - proj) @ b)
projection of a on b: [3. 0.] remainder: [0. 4.] remainder · b = 0.0

The remainder is orthogonal (dot product 0) to b — the projection is the closest point to a along b.

The dot product a·b = Σaᵢbᵢ = ‖a‖‖b‖cos θ is positive for vectors pointing the same way, zero for orthogonal ones and negative for opposite ones. A linear model's prediction is the dot product of weights and features plus a bias. Cosine similarity, the dot product divided by both norms, compares direction regardless of magnitude and drives recommendation, semantic and vector search, and attention in Transformers. Projection ((a·b)/(b·b))b gives the component of a along b, with an orthogonal remainder, the basis of PCA and least squares.

Matrices & Matrix Operations

A matrix is a grid of numbers — and a dataset with rows of examples and columns of features is exactly that. Matrix multiplication applies a model to all examples at once and is what GPUs are built to do fast. This lesson covers shapes, transpose, element-wise vs matrix multiplication and the special matrices you'll meet.

A Dataset Is a Matrix

\[ X = \begin{bmatrix} 1200 & 3 & 8 \\ 850 & 2 & 15 \\ 2000 & 4 & 2 \end{bmatrix} \in \mathbb{R}^{3\times 3} \]rows = examples (houses), columns = features (area, bedrooms, age); shape is rows × columns

Matrix × Vector: Predict for Every Row at Once

\[ \hat{\mathbf{y}} = X\mathbf{w} + b \]each prediction is the dot product of one row with the weights

Matrix × Matrix

\[ (AB)_{ij} = \sum_k A_{ik}B_{kj} \qquad (m\times \color{orange}{n})\cdot(\color{orange}{n}\times p) \rightarrow (m \times p) \]the inner sizes must match; entry (i, j) = row i of A · column j of B

Matrices as Transformations

Multiplying points by a matrix moves them: rotate, scale, shear. This geometric view explains eigenvectors (3.7) and what a neural layer does to its inputs.

CellPython
import matplotlib.pyplot as plt
square = np.array([[0, 0], [1, 0], [1, 1], [0, 1], [0, 0]]).T        # 2 × 5 points
theta = np.radians(30)
R = np.array([[np.cos(theta), -np.sin(theta)], [np.sin(theta), np.cos(theta)]])   # rotate 30°
S = np.array([[2, 0], [0, 0.5]])                                                   # stretch x, squash y

fig, ax = plt.subplots(figsize=(5, 3.2))

    pts = M @ square
    ax.plot(pts[0], pts[1], marker="o", label=lab)
ax.set_aspect("equal"); ax.grid(alpha=0.3); ax.legend(loc="upper left")
plt.show()
A matrix is a rectangular array; a dataset is an m × n matrix of examples by features. Matrix–vector multiplication Xw computes predictions for all examples at once, and matrix–matrix multiplication requires matching inner dimensions ((m×n)(n×p) → m×p), with each entry a row-column dot product; it is not commutative. Element-wise (Hadamard) multiplication differs from the matrix product (@). The transpose swaps rows and columns, with (AB)ᵀ = BᵀAᵀ; the identity leaves matrices unchanged; covariance and XᵀX are symmetric. Geometrically, matrices are linear transformations such as rotation and scaling, and a neural-network layer is a matrix multiplication plus bias.
3.6

Linear Systems, Inverses & Determinants

Many problems reduce to "find the unknowns that satisfy several equations at once" — a linear system. Matrices let us write and solve them in one line. The determinant tells us whether a unique solution exists, and the inverse undoes a matrix. These ideas lead directly to how linear regression is solved.

A System as a Matrix Equation

\[ \begin{cases} 2x + y = 7 \\ x - y = 2 \end{cases} \quad\Longleftrightarrow\quad \underbrace{\begin{bmatrix} 2 & 1 \\ 1 & -1 \end{bmatrix}}_{A}\underbrace{\begin{bmatrix} x \\ y \end{bmatrix}}_{\mathbf{x}} = \underbrace{\begin{bmatrix} 7 \\ 2 \end{bmatrix}}_{\mathbf{b}} \]
CellPython
import numpy as np
A = np.array([[2, 1], [1, -1]], dtype=float)
b = np.array([7, 2], dtype=float)
x = np.linalg.solve(A, b)
print("solution x, y =", x)
print("check A @ x =", A @ x)
solution x, y = [3. 1.] check A @ x = [7. 2.]

Geometrically each equation is a line; the solution is where they cross. Three outcomes are possible:

LinesSolutionsDeterminant
Cross onceExactly one\(\det A \ne 0\)
ParallelNone\(\det A = 0\)
Same lineInfinitely many\(\det A = 0\)

The Determinant

\[ \det\begin{bmatrix} a & b \\ c & d \end{bmatrix} = ad - bc \]geometrically: how much the matrix scales area (volume in 3-D); 0 means it squashes space flat
CellPython
print("det A =", round(np.linalg.det(A), 6))          # 2·(−1) − 1·1 = −3 → unique solution

S = np.array([[1, 2], [2, 4]], dtype=float)            # second row = 2 × first row
print("det S =", round(np.linalg.det(S), 6))
try:
    np.linalg.solve(S, [3, 6])
except np.linalg.LinAlgError as e:

The Inverse

Rank: How Much Independent Information?

The rank is the number of linearly independent rows (or columns). If one feature is an exact combination of others — say total = price × qty stored alongside price and qty in a linear model, or temperature in both °C and °F — the matrix is rank-deficient: \(X^\top X\) can't be inverted and linear models become unstable. This is multicollinearity.

Over-Determined Systems: More Equations than Unknowns

Real data has many more rows than features, and no line passes through every point. Least squares finds the parameters that minimise the squared error — solved by the normal equation:

\[ \mathbf{w} = (X^\top X)^{-1} X^\top \mathbf{y} \]we derive and use this in Lesson 3.17
A system of linear equations can be written Ax = b and solved with np.linalg.solve. A unique solution exists when det A ≠ 0; a zero determinant means the transformation collapses space, giving no or infinitely many solutions. The inverse satisfies A⁻¹A = I, but solving directly is faster and more stable than computing it. Rank counts independent rows or columns; rank deficiency from perfectly correlated features (multicollinearity) makes XᵀX singular or ill-conditioned. With more equations than unknowns, least squares solves the normal equation w = (XᵀX)⁻¹Xᵀy.

When a matrix transforms space, most vectors change direction. Eigenvectors are the special directions that only get stretched or shrunk; the stretch factor is the eigenvalue. Applied to a dataset's covariance matrix, eigenvectors point along the directions where the data varies most — the idea behind Principal Component Analysis (PCA), the classic way to reduce many features to a few.

Second Derivative: Curvature

\(f''(x)\) is the derivative of the derivative. Positive → curving up (a valley: minimum); negative → curving down (a hill: maximum). At a point where \(f'(x) = 0\), the second derivative tells you which you've found.

A derivative f′(x) is the instantaneous rate of change — the slope of the tangent — defined as the limit of (f(x + h) − f(x))/h as h → 0. Key rules are the constant, power, sum, exponential (eˣ)′ = eˣ, logarithm (ln x)′ = 1/x, product and chain rules. In ML the derivative of the loss with respect to a parameter, such as −2x(y − wx) for squared error, gives the direction and steepness of change, telling training which way to adjust it; the sigmoid's derivative is σ(1 − σ). The second derivative measures curvature and distinguishes minima from maxima.
3.9

Partial Derivatives & Gradients

Real models have many parameters — a line has two, an LLM has billions. A partial derivative measures the effect of changing one parameter while holding the others still. Collect all of them into a vector and you have the gradient: the direction of steepest increase of the loss. Its opposite is the way to train.

Partial Derivatives

\[ f(w, b) = w^2 + 3wb + b^2 \qquad \frac{\partial f}{\partial w} = 2w + 3b \qquad \frac{\partial f}{\partial b} = 3w + 2b \]\(\partial\) ("partial"): differentiate with respect to one variable, treating the others as constants

The Gradient

\[ \nabla f = \left[\frac{\partial f}{\partial w_1},\; \frac{\partial f}{\partial w_2},\; \dots,\; \frac{\partial f}{\partial w_n}\right] \]points uphill (steepest increase); \(-\nabla f\) points downhill; its length is the steepness

Gradient of Mean Squared Error for a Line

\[ L(w, b) = \frac{1}{n}\sum_{i=1}^{n}\big(y_i - (w x_i + b)\big)^2 \qquad \frac{\partial L}{\partial w} = -\frac{2}{n}\sum x_i\,(y_i - \hat{y}_i) \qquad \frac{\partial L}{\partial b} = -\frac{2}{n}\sum (y_i - \hat{y}_i) \]

Chain Rule & Backpropagation

Models are functions inside functions: a weighted sum feeds an activation, which feeds a loss. The chain rule gives the derivative of such compositions by multiplying the derivatives of each step. Applied systematically from the loss backwards through a network, it's called backpropagation — the algorithm that trains every neural network.

The Rule

\[ y = f(g(x)) \quad\Rightarrow\quad \frac{dy}{dx} = \frac{dy}{dg}\cdot\frac{dg}{dx} \]"how much y changes per g" × "how much g changes per x"

Example: \(y = (3x + 1)^2\). Outer \(f(g) = g^2\), inner \(g = 3x + 1\). So \(\frac{dy}{dx} = 2g \cdot 3 = 6(3x + 1)\).

A Single Neuron as a Chain

x, w, b
→
z = w·x + b
→
p = σ(z)
→
L = −[y log p + (1−y) log(1−p)]
\[ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial p}\cdot\frac{\partial p}{\partial z}\cdot\frac{\partial z}{\partial w} = \left(\frac{p - y}{p(1-p)}\right)\cdot p(1 - p)\cdot x = (p - y)\,x \]the messy terms cancel — which is exactly why sigmoid is paired with log-loss
Cell — forward pass, backward pass, checkPython
import numpy as np
sigmoid = lambda z: 1 / (1 + np.exp(-z))

def forward(w, b, x, y):
    z = w * x + b
    p = sigmoid(z)
    L = -(y * np.log(p) + (1 - y) * np.log(1 - p))
    return z, p, L

x, y = 2.0, 1.0          # one example whose true label is 1
w, b = -0.5, 0.1

dL_dp = (p - y) / (p * (1 - p))      # local derivative of each step...
dp_dz = p * (1 - p)
dz_dw, dz_db = x, 1.0
dL_dw = dL_dp * dp_dz * dz_dw        # ...multiplied along the chain
dL_db = dL_dp * dp_dz * dz_db

Backpropagation in a Tiny Network

A network with one hidden layer, trained on the XOR problem (which no straight line can solve). The backward pass applies the chain rule layer by layer, re-using the downstream gradient at each step:

Cell — a 2-4-1 network learning XORPython
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
Y = np.array([[0], [1], [1], [0]], dtype=float)

rng = np.random.default_rng(1)
W1, b1 = rng.normal(0, 1, (2, 4)), np.zeros((1, 4))
W2, b2 = rng.normal(0, 1, (4, 1)), np.zeros((1, 1))
lr = 1.0

for step in range(3001):
    # forward
    H = np.tanh(X @ W1 + b1)                 # hidden layer
    P = sigmoid(H @ W2 + b2)                 # output probability
    loss = -np.mean(Y * np.log(P) + (1 - Y) * np.log(1 - P))
    # backward (chain rule, from the loss towards the inputs)
    dZ2 = (P - Y) / len(X)                   # sigmoid + log-loss shortcut
    dW2, db2 = H.T @ dZ2, dZ2.sum(axis=0, keepdims=True)
    dH = dZ2 @ W2.T                          # pass the gradient back through W2
    dZ1 = dH * (1 - H ** 2)                  # through tanh: tanh'(a) = 1 − tanh²(a)
    dW1, db1 = X.T @ dZ1, dZ1.sum(axis=0, keepdims=True)
    # update
    W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    if step % 1000 == 0:
        print(f"step {step:4d}  loss {loss:.4f}")

print("predictions:", P.ravel().round(3), "-> rounded", P.ravel().round().astype(int), "target", Y.ravel().astype(int))
step 0 loss 0.6712 step 1000 loss 0.0024 step 2000 loss 0.0012 step 3000 loss 0.0008 predictions: [0. 0.999 0.999 0.001] -> rounded [0 1 1 0] target [0 1 1 0]
Frameworks such as PyTorch and TensorFlow do this automatically (automatic differentiation): you write the forward pass, call loss.backward(), and they apply the chain rule through every operation for you (Module 8).

Vanishing and Exploding Gradients

Backprop multiplies many local derivatives together. If they're mostly below 1 (sigmoid's slope is at most 0.25), the product shrinks towards zero in deep networks and early layers stop learning — vanishing gradients. If they're above 1, it blows up — exploding gradients. Remedies: ReLU activations, careful initialisation, normalisation layers, residual connections and gradient clipping (Module 8).

CellPython

The chain rule differentiates composed functions by multiplying local derivatives: d f(g(x))/dx = f′(g(x))·g′(x). A neuron's loss is a chain — linear combination, activation, loss — and for sigmoid with log-loss the gradient simplifies to (p − y)x. Backpropagation applies the chain rule from the loss backwards through each layer, reusing downstream gradients, to compute all parameter gradients efficiently; frameworks automate it with automatic differentiation. Because many local derivatives are multiplied, deep networks can suffer vanishing or exploding gradients, mitigated with ReLU, initialisation, normalisation, residual connections and clipping.

Optimization & Gradient Descent

Training a model means optimization: finding the parameters that minimise the loss. Gradient descent does it by repeatedly stepping downhill along the negative gradient. This lesson covers the update rule, the learning rate, batch vs stochastic vs mini-batch, convexity and local minima, the improved optimisers (Momentum, Adam) and a word on constraints.

The Update Rule

\[ \theta_{\text{new}} = \theta_{\text{old}} - \eta\,\nabla L(\theta_{\text{old}}) \]\(\theta\) = parameters · \(\eta\) ("eta") = learning rate, the step size
Cell — fit a line by gradient descentPython

x = rng.uniform(0, 10, 50)
y = 3 * x + 4 + rng.normal(0, 1, 50)

def loss_grad(w, b):
    err = y - (w * x + b)

theta = np.array([0.0, 0.0])
lr = 0.02
history = []

Cell — plain GD vs Adam on a narrow valleyPython
Lf = lambda p: 0.5 * p[0]**2 + 25 * p[1]**2          # 50× steeper in one direction
gf = lambda p: np.array([p[0], 50 * p[1]])

def run(method, steps=100):
    p = np.array([-8.0, 1.0]); m = np.zeros(2); v = np.zeros(2)
    for t in range(1, steps + 1):
        g = gf(p)
        if method == "gd":
            p = p - 0.035 * g                             # bigger than ~0.04 diverges in the steep direction
        else:                                             # Adam
            m = 0.9 * m + 0.1 * g
            v = 0.999 * v + 0.001 * g**2
            m_hat, v_hat = m / (1 - 0.9**t), v / (1 - 0.999**t)
            p = p - 0.3 * m_hat / (np.sqrt(v_hat) + 1e-8)
    return Lf(p)

Constraints and Closed Forms

Some problems have constraints (weights must be positive, a budget must not be exceeded). Techniques include Lagrange multipliers, projected gradient descent and dedicated solvers (scipy.optimize, linear programming). And some problems need no iteration at all: linear regression has a closed-form solution, the normal equation (Lesson 3.17).

Optimization finds parameters minimising a loss. Gradient descent updates θ ← θ − η∇L, where the learning rate η must be neither too small (slow) nor too large (divergence), and feature scaling improves conditioning. Batch, stochastic and mini-batch variants trade accuracy of each gradient against speed, with mini-batches standard; an epoch is a full pass over the data. Convex problems such as linear and logistic regression have a single minimum, while neural networks are non-convex with local minima and saddle points. Momentum, RMSProp and Adam adapt steps using running averages of gradients, schedules adjust the learning rate, constrained problems use Lagrange multipliers or specialised solvers, and some problems have closed-form solutions.

  • Compare floats with tolerances (np.isclose), never ==

Bayes' Theorem

Bayes' theorem tells you how to update a belief when you see new evidence. It turns "how likely is this evidence if the hypothesis is true?" into "how likely is the hypothesis, given the evidence?" — the reasoning behind medical test interpretation, spam filters, fraud scoring and the whole field of Bayesian machine learning.

The Formula

\[ P(H \mid E) = \frac{P(E \mid H)\;P(H)}{P(E)} \qquad P(E) = P(E \mid H)P(H) + P(E \mid \bar{H})P(\bar{H}) \]posterior = likelihood × prior ÷ evidence

Naive Bayes: A Classifier Built on Bayes

\[ P(\text{spam} \mid w_1, \dots, w_n) \;\propto\; P(\text{spam})\prod_{i} P(w_i \mid \text{spam}) \]"naive": assumes words are independent given the class — rarely true, yet works well for text
Cell — a tiny spam filter by hand, in log spacePython
import numpy as np
train = [("win cash prize now", "spam"), ("cheap cash offer", "spam"), ("win a free prize", "spam"),
         ("meeting at noon", "ham"), ("project update attached", "ham"), ("lunch at noon today", "ham")]
vocab = sorted({w for text, _ in train for w in text.split()})

def word_probs(label):
    words = [w for text, l in train if l == label for w in text.split()]
    return {w: (words.count(w) + 1) / (len(words) + len(vocab)) for w in vocab}   # +1 smoothing

priors = {c: sum(l == c for _, l in train) / len(train) for c in ("spam", "ham")}
probs = {c: word_probs(c) for c in priors}

def classify(text):
    scores = {c: np.log(priors[c]) + sum(np.log(probs[c][w]) for w in text.split() if w in vocab)
              for c in priors}
    total = np.logaddexp(*scores.values())                       # normalise in log space
    return {c: round(float(np.exp(s - total)), 3) for c, s in scores.items()}

for msg in ["win cash now", "meeting update today", "free lunch prize"]:
    print(f"{msg!r:<24} {classify(msg)}")
'win cash now' {'spam': 0.941, 'ham': 0.059} 'meeting update today' {'spam': 0.1, 'ham': 0.9} 'free lunch prize' {'spam': 0.728, 'ham': 0.272}
Bayes' theorem P(H|E) = P(E|H)P(H)/P(E) updates a prior belief with the likelihood of new evidence to give a posterior, with P(E) expanded by total probability. With rare events the base rate dominates, so even accurate tests yield many false positives — the base-rate fallacy, which explains the importance of precision in imbalanced classification. Posteriors become priors for sequential updating. Naive Bayes classifies by combining a class prior with per-feature likelihoods under a conditional-independence assumption, using Laplace smoothing and log probabilities, and works well for text such as spam filtering.

Putting It Together: Regression from Scratch & Exercises

Linear regression uses almost every idea in this module: data as a matrix, predictions as a matrix-vector product, a loss justified by the normal distribution, its gradient by the chain rule, and two ways to minimise it — a closed-form linear-algebra solution and gradient descent. Build it both ways, check against scikit-learn, then test yourself with exercises.

The Problem

\[ \hat{\mathbf{y}} = X\mathbf{w} \qquad L(\mathbf{w}) = \frac{1}{n}\|\mathbf{y} - X\mathbf{w}\|^2 \qquad \nabla L = -\frac{2}{n}X^\top(\mathbf{y} - X\mathbf{w}) \]a column of 1s in X absorbs the bias b

Way 1: The Normal Equation (Linear Algebra)

Set the gradient to zero: \(X^\top X\mathbf{w} = X^\top\mathbf{y}\), so

\[ \mathbf{w}^{*} = (X^\top X)^{-1}X^\top \mathbf{y} \]
Cell — house prices: area and agePython
import numpy as np
rng = np.random.default_rng(7)
n = 200
area = rng.uniform(600, 2500, n)                 # sq ft
age = rng.uniform(0, 30, n)                      # years
price = 15 + 0.07 * area - 0.8 * age + rng.normal(0, 8, n)   # ₹ lakh, with noise

X = np.column_stack([np.ones(n), area, age])     # bias column + features
w_normal = np.linalg.solve(X.T @ X, X.T @ price) # solve, rather than invert
print("normal equation:  b = %.3f, w_area = %.4f, w_age = %.3f" % tuple(w_normal))
normal equation: b = 16.173, w_area = 0.0689, w_age = -0.871

Way 2: Gradient Descent (Calculus)

Cell — standardise first, then descendPython
mu, sd = X[:, 1:].mean(axis=0), X[:, 1:].std(axis=0)
Xs = np.column_stack([np.ones(n), (X[:, 1:] - mu) / sd])     # z-scores: a round bowl, not a ravine

w = np.zeros(3)
lr = 0.1
for step in range(500):
    grad = -2 / n * Xs.T @ (price - Xs @ w)
    w -= lr * grad

# convert back to original units: w_j = w_j' / sd_j ;  b = b' − Σ w_j' μ_j / sd_j
w_orig = np.r_[w[0] - np.sum(w[1:] * mu / sd), w[1:] / sd]
print("gradient descent: b = %.3f, w_area = %.4f, w_age = %.3f" % tuple(w_orig))
print("MSE:", round(np.mean((price - X @ w_orig) ** 2), 3))
gradient descent: b = 16.173, w_area = 0.0689, w_age = -0.871 MSE: 53.594

The normal equation is exact and fast for a few thousand features, but costs roughly \(d^3\) for d features and needs all data in memory. Gradient descent scales to millions of features and streaming mini-batches — which is why deep learning uses it.

Linear regression combines the module's maths: data as a matrix with a bias column, predictions Xw, mean squared error justified by Gaussian noise, gradient −(2/n)Xᵀ(y − Xw) from the chain rule, and two solutions — the closed-form normal equation w = (XᵀX)⁻¹Xᵀy, solved with a linear solver and costly as features grow, and gradient descent on standardised features, which scales to large problems; both match scikit-learn. The mathematics of machine learning has three pillars. Linear algebra represents data and models as vectors and matrices — norms, dot products and cosine similarity, matrix multiplication, linear systems, determinants, rank and eigen-decomposition for PCA. Calculus provides derivatives, gradients and the chain rule, which backpropagation uses to train models by gradient descent and its variants, with care for numerical stability. Probability — counting, conditional probability, Bayes' theorem and distributions — quantifies uncertainty and, through maximum likelihood, defines loss functions. Linear regression solved by the normal equation and by gradient descent brings them together.
