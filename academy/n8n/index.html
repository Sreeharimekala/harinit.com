Before You Start

How to use this course

Prerequisites: Basic SQL, JSON, REST APIs and programming knowledge are helpful. Since you already have experience in SQL, Python, Azure Data Factory, data engineering and monitoring, you can progress beyond basic no-code automation and learn how to build production-grade automation solutions.
🚀 Start here — how to use this course
  1. Work through the chapters in order: each one builds on the previous chapter. Begin with Chapter 1, or use Continue Learning → to jump to your next unfinished section.
  2. Inside a chapter, read a section, try the example, then press Mark Lesson Complete. Your progress is saved in this browser and shown on this page.
  3. Do every lab in your own local n8n (Chapter 3 shows how to set it up with Docker). Building is how the concepts stick.
  4. Look up unfamiliar words in the 📖 Glossary, and use the search box to find any topic across all chapters.
  5. Answer the interview questions and tick the checklist at the end of each chapter before moving on.
  6. Finish with the 12 real-time projects and the capstone to build a portfolio.
