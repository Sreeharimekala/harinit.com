11.1

JavaScript in n8n

n8n is a low-code workflow automation platform, but real workflows often need custom logic. The Code node lets you write JavaScript to transform input data, calculate values, validate records and produce structured output.

Expressions

Best for dynamic values and small field-level calculations inside supported fields.

Edit Fields

Best for ordinary field mapping, adding, renaming and removing properties.

Code node

Best for custom programming logic, loops, complex transformations and reusable functions.

Core nodes

Best for visual routing, filtering, merging, batching and workflow control.

11.2

JavaScript fundamentals

Syntax · data types · operators

JavaScript is a programming language used to add logic and transform data. Start with statements, expressions, values, operators and comments.

Basic output and comments

// Single-line comment
/*
  Multi-line comment
*/
const message = "Hello from n8n";
const total = 100 + 25;

Common data types

TypeExampleUse
String"Hello"Names, IDs, messages
Number125.50Amounts, quantities
BooleantrueFlags and validation
UndefinedundefinedA variable with no assigned value
NullnullExplicitly empty value
Array[10, 20, 30]Ordered collection
Object{ name: "Asha" }Related key-value data

Operators

// Arithmetic
const amount = 100 + 25;
const balance = 100 - 20;
const lineTotal = 5 * 200;
const average = 100 / 4;
const remainder = 10 % 3;

// Comparison
const isPaid = status === "Paid";
const isLarge = amount >= 1000;

// Logical
const canProcess = isPaid && isLarge;
const needsReview = !isPaid || amount > 10000;
Prefer strict equality: use === and !== in most application logic. They compare values without automatically converting types, unlike == and !=.
11.3

Variables and constants

let · const · scope

Variables store values that code can use. JavaScript commonly uses const for bindings that will not be reassigned and let for bindings that need reassignment.

const workflowName = "Daily Customer Load";
let processedCount = 0;

processedCount = processedCount + 1;

const customer = {
  id: 101,
  name: "Asha"
};

// The object binding is const, but its properties can still change:
customer.name = "Asha Rao";
KeywordCan reassign?ScopeRecommendation
constNoBlock scopeDefault choice when the binding does not need reassignment.
letYesBlock scopeUse for counters and values that change.
varYesFunction scopeUsually avoid in modern JavaScript because its scoping behaviour can be confusing.

Variable naming rules

  • Use meaningful names such as customerId, totalAmount and isValid.
  • JavaScript variable names are case-sensitive.
  • Names cannot start with a number and cannot contain spaces.
  • Use camelCase for ordinary variables and functions.
Use const for most declarations. Change to let only when reassignment is part of the logic.
11.4

Functions

Reusable logic

A function is a reusable block of code. It can accept inputs called parameters, perform operations and return a result.

Function declaration

function calculateTotal(quantity, unitPrice) {
  return quantity * unitPrice;
}

const total = calculateTotal(3, 250);
// total = 750

Default parameters

function applyDiscount(amount, discount = 0) {
  return amount - discount;
}

const finalAmount = applyDiscount(1000, 100);

Function with validation

function isValidEmail(email) {
  if (typeof email !== "string") {
    return false;
  }

  const normalized = email.trim();
  return normalized.includes("@") && normalized.includes(".");
}

const valid = isValidEmail("user@example.com");

Why functions matter in n8n

  • Keep Code node logic organized.
  • Reuse calculations for every record.
  • Separate validation from transformation.
  • Make code easier to test and maintain.
11.5

Arrow functions

Compact function syntax

Arrow functions provide a shorter syntax for functions and are commonly used with array methods such as map(), filter() and reduce().

// Traditional function
function double(value) {
  return value * 2;
}

// Equivalent arrow function
const doubleArrow = (value) => {
  return value * 2;
};

// Short expression body: implicit return
const triple = value => value * 3;

// Multiple parameters
const multiply = (a, b) => a * b;

Arrow functions with arrays

const prices = [100, 200, 300];

const doubled = prices.map(price => price * 2);
const expensive = prices.filter(price => price >= 200);
const total = prices.reduce((sum, price) => sum + price, 0);

Arrow functions do not have their own this binding. For beginner data-transformation tasks, the most important skill is recognizing their use as concise callbacks.

11.6

Loops

Repeat operations

Loops repeat code. JavaScript offers several loop styles. Choose the one that makes the intent easiest to understand.

for loop

const values = [10, 20, 30];

for (let i = 0; i < values.length; i++) {
  // Access one value by index
  const currentValue = values[i];
}

for...of loop

const customers = ["Asha", "Ravi", "Meena"];

for (const customer of customers) {
  // Process each value
}

while loop

let count = 0;

while (count < 3) {
  count++;
}

Loop control

  • break exits the loop.
  • continue skips the current iteration and moves to the next one.
Make sure a while loop has a condition that eventually becomes false. Otherwise it can run indefinitely and cause execution problems.
11.7

Conditional statements

if · else · switch

Conditional statements let your code choose what to do based on a value or business rule.

if / else if / else

const amount = 7500;
let category;

if (amount >= 10000) {
  category = "High Value";
} else if (amount >= 5000) {
  category = "Medium Value";
} else {
  category = "Standard";
}

switch statement

const status = "Approved";
let action;

switch (status) {
  case "Approved":
    action = "Process order";
    break;
  case "Pending":
    action = "Wait for approval";
    break;
  case "Rejected":
    action = "Notify requester";
    break;
  default:
    action = "Review unknown status";
}

Truthy and falsy values

JavaScript treats some values as false in conditions: false, 0, -0, "", null, undefined and NaN. Most other values—including empty arrays and empty objects—are truthy.

For business rules, compare explicit values when possible. For example, status === "Active" is clearer than relying on the truthiness of a status field.
11.8

Arrays and objects

Core data structures

Arrays store ordered collections. Objects store named properties. n8n data is JSON-like, so understanding these structures is essential when reading and transforming input items.

Array examples

const departments = ["Finance", "IT", "HR"];

const first = departments[0];
departments.push("Operations");

const count = departments.length;

Object examples

const employee = {
  employeeId: 501,
  name: "Ravi",
  department: "IT",
  active: true
};

const employeeName = employee.name;
employee.department = "Data Engineering";

Nested objects and arrays

const order = {
  orderId: 9001,
  customer: {
    name: "Asha",
    city: "Hyderabad"
  },
  items: [
    { sku: "KB-01", quantity: 2, price: 500 },
    { sku: "MS-02", quantity: 1, price: 300 }
  ]
};

const city = order.customer.city;
const firstSku = order.items[0].sku;

11.9

JSON parsing

JSON.stringify · JSON.parse

JSON (JavaScript Object Notation) is a text format for exchanging structured data. In JavaScript, JSON text can be parsed into an object, and an object can be serialized into JSON text.

Parse JSON text into an object

const jsonText = '{"customerId":101,"name":"Asha"}';

const customer = JSON.parse(jsonText);

const customerName = customer.name;

Convert an object into JSON text

const order = {
  orderId: 9001,
  amount: 1250
};

const jsonText = JSON.stringify(order);

Safe JSON parsing

const rawPayload = $json.payload;

let parsed;

try {
  parsed = typeof rawPayload === "string"
    ? JSON.parse(rawPayload)
    : rawPayload;
} catch (error) {
  throw new Error(`Invalid JSON payload: ${error.message}`);
}

return [{
  json: {
    parsed_payload: parsed
  }
}];
Do not call JSON.parse() on a value that is already an object. Check the type first. JSON does not support JavaScript functions, undefined values or comments.

JSON in n8n

n8n items usually contain a json property holding the item's structured data. In the Code node, $input.all() gives you the incoming items. You usually work with item.json directly; parsing is needed only when a field contains JSON as text.

11.10

Date manipulation

JavaScript Date · Luxon in n8n

JavaScript includes the Date object for representing timestamps. In n8n, Luxon is also widely used in expressions and is often preferable for timezone-aware date formatting and arithmetic.

Native JavaScript Date

const now = new Date();

const isoTimestamp = now.toISOString();

const tomorrow = new Date(now);
tomorrow.setDate(tomorrow.getDate() + 1);

const year = now.getFullYear();
const month = now.getMonth() + 1; // JavaScript months are zero-based

Parse an ISO timestamp

const sourceDate = new Date("2026-11-21T09:30:00Z");

if (Number.isNaN(sourceDate.getTime())) {
  throw new Error("Invalid date");
}

Luxon in n8n expressions

// Current date/time
{{ $now.toISO() }}

// Add 7 days
{{ $now.plus({ days: 7 }).toISODate() }}

// Format date
{{ $now.toFormat('dd/LL/yyyy') }}

When using Luxon directly in Code, availability depends on the Code node runtime and n8n-provided helpers. Do not assume expression-only helper names are global JavaScript variables in Code. Native JavaScript Date is available for basic date work.

Timezone: toISOString() represents a UTC timestamp. Do not confuse it with a local display string. Confirm whether the source timestamp is UTC, offset-aware or local time before converting it.
11.11

JavaScript in Code Node

Run Once for All Items · Run Once for Each Item

The Code node supports JavaScript and provides n8n-specific helpers to read input items and return output items. It has two main modes. The mode determines how the code is invoked and what output structure you should return.

ModeHow it runsTypical use
Run Once for All ItemsCode executes once for the full input collection.Aggregate, compare, reshape or process the entire batch.
Run Once for Each ItemCode executes separately for each input item.Apply a focused transformation to the current item.

Read all input items

const items = $input.all();

return items.map((item) => {
  const quantity = Number(item.json.quantity ?? 0);
  const price = Number(item.json.unit_price ?? 0);

  return {
    json: {
      ...item.json,
      line_total: quantity * price
    }
  };
});

Read the current item in per-item mode

// Run Once for Each Item
const quantity = Number($json.quantity ?? 0);
const price = Number($json.unit_price ?? 0);

return {
  json: {
    ...$json,
    line_total: quantity * price
  }
};

Useful Code node helpers

HelperPurpose
$input.all()Get all input items.
$input.first()Get the first input item.
$input.itemAccess the current input item in relevant contexts.
$jsonAccess current item JSON in per-item mode.
$('Node Name').all()Access all output items from a named node.
$executionAccess execution metadata.

Output structure

// All-items mode: return an array of n8n items
return [
  { json: { id: 1, status: "OK" } },
  { json: { id: 2, status: "OK" } }
];
Common Code node mistake: returning a plain array of business objects instead of n8n item objects in all-items mode. Use the documented n8n item structure, normally { json: { ... } }. Check the current Code node documentation for the selected mode and runtime.

Item linking

When a Code node changes the number or order of items, item linking can matter for later expressions that reference earlier nodes. Straightforward one-to-one transformations are often linked automatically. If you create, combine or reorder items in more complex ways, inspect the item-linking guidance and preserve relationships where needed.

11.12

Processing multiple records

Batch transformations

In n8n, incoming data is typically an array of items. In all-items mode, you can process that collection using JavaScript array methods or loops. Many built-in nodes already process multiple items, so use the Code node only when custom logic is needed.

Example input items

[
  { json: { employee_id: 101, name: "Asha", salary: "50000" } },
  { json: { employee_id: 102, name: "Ravi", salary: "60000" } },
  { json: { employee_id: 103, name: "Meena", salary: "55000" } }
]

Transform all records using map()

const items = $input.all();

return items.map((item) => {
  const salary = Number(item.json.salary);

  return {
    json: {
      ...item.json,
      salary: Number.isFinite(salary) ? salary : null,
      annual_salary: Number.isFinite(salary) ? salary * 12 : null
    }
  };
});

Filter records in code

const items = $input.all();

return items.filter(item => {
  return item.json.active === true;
});

Aggregate all records into one output item

const items = $input.all();

const totalSalary = items.reduce((sum, item) => {
  return sum + Number(item.json.salary ?? 0);
}, 0);

return [{
  json: {
    employee_count: items.length,
    total_salary: totalSalary
  }
}];

Loop through records with for...of

const items = $input.all();
const results = [];

for (const item of items) {
  const record = item.json;

  results.push({
    json: {
      employee_id: record.employee_id,
      display_name: String(record.name ?? "").trim().toUpperCase()
    }
  });
}

return results;
Use map() for one-to-one transformation, filter() to retain matching items, reduce() to calculate one summary, and for...of when the processing steps are easier to express imperatively.
11.13

Error handling in JavaScript

try · catch · throw

Error handling lets you detect invalid data and unexpected failures, then decide whether to return a controlled result or stop the workflow. Do not silently hide errors that should be investigated.

try / catch

try {
  const result = JSON.parse($json.payload);

  return [{
    json: {
      valid: true,
      data: result
    }
  }];
} catch (error) {
  return [{
    json: {
      valid: false,
      error_message: error.message
    }
  }];
}

Throw an error to fail the node

const amount = Number($json.amount);

if (!Number.isFinite(amount)) {
  throw new Error("Amount must be a valid number");
}

return {
  json: {
    ...$json,
    amount
  }
};

Validate required fields

const requiredFields = ["customer_id", "email"];
const missingFields = requiredFields.filter(field => {
  return $json[field] === undefined ||
         $json[field] === null ||
         String($json[field]).trim() === "";
});

if (missingFields.length > 0) {
  throw new Error(
    `Missing required fields: ${missingFields.join(", ")}`
  );
}

return {
  json: {
    ...$json,
    validation_status: "Valid"
  }
};

Choose an error strategy

StrategyBehaviourWhen appropriate
Throw an errorFails the Code node and follows workflow error behaviour.Critical invalid data or an unrecoverable condition.
Return an error resultOutputs an item describing the record-level problem.Expected validation failures that should be reviewed downstream.
Use workflow error handlingConfigure node/workflow error behaviour and an Error Trigger workflow where appropriate.Centralized notifications, logging and recovery.
Do not use an empty catch block. It hides the cause of the failure. Log or return useful context, or rethrow the error when the workflow should fail.

Record-level handling example

const items = $input.all();

return items.map((item) => {
  const amount = Number(item.json.amount);

  if (!Number.isFinite(amount)) {
    return {
      json: {
        ...item.json,
        processing_status: "Rejected",
        error_message: "Invalid amount"
      }
    };
  }

  return {
    json: {
      ...item.json,
      amount,
      processing_status: "Accepted"
    }
  };
});

This approach lets the workflow continue with a result for each record. If invalid data must stop the whole execution, throw an error instead. Choose based on the business requirement.

11.14

Reusable JavaScript patterns for n8n

Pattern A — Normalize customer details

const items = $input.all();

return items.map(({ json }) => ({
  json: {
    customer_id: String(json.customer_id ?? "").trim(),
    name: String(json.name ?? "").trim(),
    email: String(json.email ?? "").trim().toLowerCase()
  }
}));

Pattern B — Calculate order totals

const items = $input.all();

return items.map(item => {
  const quantity = Number(item.json.quantity);
  const price = Number(item.json.unit_price);

  if (!Number.isFinite(quantity) || !Number.isFinite(price)) {
    return {
      json: { ...item.json, calculation_status: "Invalid input" }
    };
  }

  return {
    json: {
      ...item.json,
      total: Math.round(quantity * price * 100) / 100,
      calculation_status: "Success"
    }
  };
});

Pattern C — Remove duplicate records by key

const items = $input.all();
const seen = new Set();
const unique = [];

for (const item of items) {
  const key = String(item.json.customer_id);

  if (!seen.has(key)) {
    seen.add(key);
    unique.push(item);
  }
}

return unique;

Pattern D — Group totals by category

const items = $input.all();
const totals = {};

for (const item of items) {
  const category = item.json.category ?? "Unknown";
  const amount = Number(item.json.amount ?? 0);

  totals[category] = (totals[category] ?? 0) + amount;
}

return Object.entries(totals).map(([category, total]) => ({
  json: { category, total }
}));
These examples are starting patterns. Add validation for your real input schema, and consider whether a built-in n8n node would make the workflow simpler and easier to maintain.

11.16

Interview questions and answers

  1. Why is JavaScript useful in n8n?
    It enables custom data transformation, validation, calculations and logic in the Code node.
  2. What is the difference between let and const?
    let allows reassignment; const does not allow reassignment of the binding.
  3. What is the difference between const and immutability?
    Const prevents rebinding the variable; it does not make an object or array deeply immutable.
  4. What is block scope?
    A variable declared with let or const is available only inside the block where it is declared.
  5. What is a function?
    A reusable block of code that can accept parameters and return a value.
  6. What is an arrow function?
    A concise function syntax commonly used for callbacks and array methods.
  7. What does map() do?
    Creates a new array by transforming each element.
  8. What does filter() do?
    Creates a new array containing elements that pass a condition.
  9. What does reduce() do?
    Combines array elements into a single accumulated result.
  10. What is the difference between for and for...of?
    A traditional for loop provides index control; for...of iterates directly over iterable values.
  11. What does break do?
    Exits the current loop or switch statement.
  12. What does continue do?
    Skips the rest of the current loop iteration.
  13. What is strict equality?
    === compares values without implicit type conversion.
  14. What is the difference between an array and an object?
    An array is an ordered collection; an object stores named key-value properties.
  15. What does JSON.parse() do?
    Converts valid JSON text into a JavaScript value.
  16. What does JSON.stringify() do?
    Serializes a JavaScript value into JSON text.
  17. How do you handle invalid JSON?
    Wrap JSON.parse() in try/catch and return or throw a meaningful error.
  18. What does new Date() return?
    A JavaScript Date object representing a date/time value.
  19. What is the difference between UTC and local time?
    UTC is a common global time standard; local time depends on a timezone and offset.
  20. What are the Code node execution modes?
    Run Once for All Items and Run Once for Each Item.
  21. How do you read all input records in Code node?
    Use $input.all().
  22. What output format should all-items mode return?
    Normally an array of n8n items, each with a json property containing the item data.
  23. What is try/catch used for?
    To catch exceptions and handle expected or recoverable errors.
  24. When should you throw an error?
    When the condition is unrecoverable or the workflow should fail rather than continue with invalid data.
