Glossary of Key n8n Terms

Plain-language definitions of the terms used throughout the course, each linked to the chapter that teaches it.

Terms 58Groups 7
How to use this page: when a chapter uses a word you do not know, look it up here, then open the linked chapter for the full explanation and examples.
📖

Automation basics

TermMeaningLearn it in
IntegrationA connection between n8n and another application or service, such as Gmail, SQL Server or Slack.Chapter 1
Low-codeBuilding mostly with visual tools, and adding small pieces of code only where needed. n8n is low-code.Chapter 1
Use caseA real business problem that an automation solves, such as routing support emails.Chapter 1
WorkflowA set of connected nodes that runs as one automated process, from a trigger to its final action.Chapter 1
Workflow automationUsing software to carry out repetitive, rule-based steps automatically instead of doing them by hand.Chapter 1
📖

Building blocks

TermMeaningLearn it in
ActionA node that performs an operation after the trigger, such as sending an email or inserting a database row.Chapter 2
Community nodeA node built by someone outside n8n and installed separately. Review it first, because it runs third-party code.Chapter 5
ConnectionThe line between two nodes. It decides the order of execution and passes one node's output to the next.Chapter 4
Core nodeA built-in node for logic or data handling, such as IF, Switch, Merge, Edit Fields or Code.Chapter 8
NodeOne step in a workflow. Each node does one job: start the workflow, fetch data, transform it, decide, or send it somewhere.Chapter 5
Sticky noteA text note on the canvas that documents what a part of the workflow does.Chapter 4
Sub-workflowA separate workflow that another workflow calls with the Execute Workflow node, so logic can be reused.Chapter 9
TriggerThe node that starts a workflow: a schedule, a webhook call, a new email, a form submission or a manual click.Chapter 6
📖

Data

TermMeaningLearn it in
$jsonIn an expression, the data of the current item coming into the node.Chapter 10
Binary dataFile content such as a PDF, image or spreadsheet, kept alongside an item's JSON data.Chapter 7
Data mappingConnecting fields from one node's output to the inputs of another node.Chapter 7
ExpressionA small piece of JavaScript inside {{ }} that inserts dynamic values, for example {{ $json.email }}.Chapter 10
ItemOne record of data passing through a workflow. Most nodes run once for each item they receive.Chapter 7
Item linkingHow n8n tracks which output item came from which input item, so you can reference earlier nodes correctly.Chapter 7
JSONJavaScript Object Notation: the text format n8n uses for data, made of key–value pairs and lists.Chapter 7
Pinned dataSaved sample output on a node, reused during testing so you do not have to call the source again.Chapter 4
📖

Running workflows

TermMeaningLearn it in
Cron expressionA five-field text pattern for schedules, for example 0 9 * * 1-5 means 09:00 on weekdays.Chapter 6
DraftThe version of a workflow you are editing. Edits autosave as a draft and do not affect production.Chapter 4
ExecutionOne run of a workflow. n8n can save each execution's data, status and errors for review.Chapter 2
Manual executionA test run started from the editor while you build.Chapter 2
PollingChecking a system repeatedly on a schedule for new data, instead of being notified.Chapter 6
Production executionA run started automatically by a trigger on a published workflow.Chapter 4
PublishMaking a workflow version live, so its triggers run automatically. In n8n 2.x it replaces the older Activate toggle.Chapter 4
WebhookA URL that starts a workflow when another system sends an HTTP request to it.Chapter 13
📖

APIs and security

TermMeaningLearn it in
APIApplication Programming Interface: the way one system lets another request or send data.Chapter 12
CredentialSaved, encrypted login details (API key, OAuth token, password) that nodes use to connect to services.Chapter 2
Encryption keyThe secret (N8N_ENCRYPTION_KEY) used to encrypt saved credentials. Losing it makes them unreadable.Chapter 3
Environment variableA configuration value given to n8n from outside, such as the port, database or timezone.Chapter 3
HTTP status codeA number in an API response: 2xx means success, 4xx means a problem with the request, 5xx a server problem.Chapter 12
OAuth 2.0A sign-in method where you approve access in the service, and n8n stores and refreshes the token.Chapter 12
PaginationGetting a large result set from an API page by page.Chapter 12
RESTA common style of web API that uses HTTP methods such as GET, POST, PUT, PATCH and DELETE.Chapter 12
Rate limitThe maximum number of requests an API accepts in a period; going over it returns errors, often 429.Chapter 12
📖

AI

TermMeaningLearn it in
AI AgentAn n8n node where an LLM decides which tools to call, step by step, to complete a task.Chapter 19
ChunkingSplitting long documents into smaller pieces before creating embeddings.Chapter 21
EmbeddingA list of numbers that represents the meaning of a piece of text, used for similarity search.Chapter 21
LLMLarge Language Model: an AI model that reads and generates text, such as GPT, Claude or Gemini.Chapter 17
MemoryStored conversation history that lets an agent remember earlier messages.Chapter 19
PromptThe instructions and context you give an LLM. A system prompt sets rules; a user prompt asks the question.Chapter 17
RAGRetrieval-Augmented Generation: finding relevant document chunks first, then letting the LLM answer from them.Chapter 21
Structured outputForcing an LLM to answer in a fixed JSON format so later nodes can use the result reliably.Chapter 18
ToolAn action an AI agent may use, such as an HTTP request, a database query or another workflow.Chapter 19
Vector storeA database that stores embeddings and finds the most similar text chunks to a question.Chapter 21
📖

Production

TermMeaningLearn it in
DEV / TEST / PRODSeparate environments for building, testing and running live workflows.Chapter 26
DockerA tool that runs applications like n8n in isolated containers, so they behave the same everywhere.Chapter 3
Docker ComposeA YAML file and command that start several containers together, such as n8n and PostgreSQL.Chapter 3
Error workflowA workflow that starts with the Error Trigger and runs when another workflow fails, usually to send an alert.Chapter 22
IdempotentSafe to run more than once: re-processing the same event does not create duplicates.Chapter 23
PostgreSQLThe database recommended for storing n8n's own data in production.Chapter 25
Queue modeA scaling setup where the main n8n process puts executions in a Redis queue and worker processes run them.Chapter 25
Reverse proxyA web server in front of n8n that handles HTTPS and forwards traffic to it.Chapter 25
VolumePersistent Docker storage. It keeps your workflows and data when a container is removed.Chapter 3
WorkerA separate n8n process that takes executions from the queue and runs them.Chapter 25
