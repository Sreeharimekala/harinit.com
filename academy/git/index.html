Before You Start

How to use this course

Prerequisites: basic command-line use; basic SQL and Python for the data-engineering phase. Software: Git 2.23+ (2.5x recommended), VS Code, Python 3.11+, Node.js 20+ (ADF), .NET SDK (SQL), Databricks CLI. A free GitHub account; optional Azure, Azure DevOps, Databricks and Fabric access for Phases 10–11.
🚀 Start here — how to use this course
  1. Work through the chapters in order. Begin with Chapter 1, or use Continue Learning → to jump to your next unfinished lesson.
  2. Inside a chapter, read each lesson, run the commands in a sandbox repository, then press Mark Lesson Complete. Progress is saved in this browser.
  3. Build the continuous Enterprise Retail Data Platform project step by step — each chapter has a 🏗️ Continuous project lesson.
  4. Look up unfamiliar words in the 📖 Glossary, and use the search box to find any topic across all chapters.
  5. Finish each chapter with the 🛠️ lab, 🎯 interview questions and 📝 quiz.
  6. Complete the 12 real-time projects and prepare with Chapter 36 – Interview Preparation.
